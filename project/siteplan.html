Website Planning Document

Site Name

Emerson Portfolio

This name is simple and direct. It puts my own name first so employers, clients and classmates can easily find me and remember the site.

Optional domain availability: emerson-portfolio.dev

Site Purpose

The site is a personal portfolio to showcase my skills, projects and experience. It provides a home page with a short introduction, a projects section with images and descriptions, an About Me section with my background and skills, and a contact section with a form so others can get in touch with me. I chose this topic because it is useful for job hunting and freelance work, and it can keep growing as I learn more.

Scenarios

  • What kind of projects has this person built?
  • What skills and technologies does this person know?
  • How can I contact this person for a job or a freelance project?
